# Windows Headless Build Folder

Unity 학습 빌드는 이 폴더에 둡니다.

권장 예시:

- `D:\Project\OverTheStrait\Builds\WindowsHeadless\OverTheStrait.exe`

루트의 `Python_mlAgent_Headless_20x_Run.bat`는 이 폴더 안의 첫 번째 `.exe` 파일을 자동으로 찾아 실행합니다.

권장 사항:

- Unity Windows 빌드 결과물을 이 폴더 바로 아래에 둡니다.
- 빌드 이름은 `OverTheStrait.exe`를 추천하지만, 다른 이름이어도 `.exe`가 하나면 자동 인식됩니다.
- 이 폴더 안에는 학습용 빌드만 두는 편이 좋습니다.
